# 📝 Formulário de Cadastro

Formulário de cadastro desenvolvido com **HTML, CSS e JavaScript**, criado como projeto de prática para desenvolver conhecimentos em desenvolvimento web e validação de formulários.

## 📋 Sobre o projeto

O projeto apresenta uma interface de cadastro onde o usuário pode informar seu e-mail, nome de usuário e senha.

O JavaScript é utilizado para verificar o preenchimento dos campos e apresentar mensagens de erro ou sucesso.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## ⚙️ Funcionalidades

* Campo de e-mail
* Campo de usuário
* Campo de senha
* Campo de confirmação de senha
* Validação dos campos
* Mensagem de erro
* Mensagem de sucesso
* Interface com tema escuro
* Efeito neon nos elementos
* Interação com JavaScript

## 📁 Estrutura do projeto

```text
formulario-cadastro/
├── index.html
├── style.css
└── script.js
```

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar:

* Estruturação de formulários com HTML
* Estilização com CSS
* Manipulação do DOM
* Eventos em JavaScript
* Validação de formulários
* Comparação de valores
* Uso de `.value`
* Uso de `textContent`
* Uso de `classList`
